{%- comment -%} The climb: every rated problem in the archive in the order I started it (left to right). The curve is a 5-problem rolling average of the problems' Codeforces ratings (trailing window), drawn as a Catmull-Rom spline converted to cubic Bezier segments. Its stroke and the translucent wash under it take a vertical "altitude" gradient (gradientUnits="userSpaceOnUse") whose colours are CSS variables, so the palette and the theme can change it. Milestone pins mark the first problem solved myself in a rating band (1000, 1200, 1400, 1600, 1800) and the hardest solved myself (the peak). The y axis runs from 750 to max(1400, peak + 100). The curve, its wash and the pins sit in .ladder-draw, which wipes in left to right each time the chart enters the viewport (home.js). Each problem is a focusable point on the curve with a tooltip (assets/js/home.js turns these into one shared tooltip that glides between points; Esc hides it).
